# Changelog

## 0.0.8 - 2026-10-30

### Changed

- Generate projects with `@vited/cli` 0.1.4, `@vited/core` 0.4.0, and `@vited/theme-mantine` 0.5.0.

## 0.0.7 - 2026-10-30

### Changed

- Generate projects with `@vited/cli` 0.1.2, `@vited/core` 0.2.0, and `@vited/theme-mantine` 0.3.0.

## 0.0.6 - 2026-10-29

### Added

- Generate `docs/favicon.svg` for new projects without overwriting an existing favicon.

## 0.0.4 - 2026-10-28

### Fixed

- Upgrade existing React and React DOM dependencies to React 19 when initializing a Vited project.

## 0.0.3 - 2026-10-28

### Fixed

- Overwrite an existing `vited-new.config.ts` when generating a comparison config, without changing `vited.config.ts`.

## 0.0.2 - 2026-10-28

### Added

- Add English and Chinese localization for CLI help, setup prompts, messages, and generated documentation. The language is detected from the system locale and can be overridden with `--lang`.

## 0.0.1 - 2023-09-02

Initial release.
